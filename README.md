# Meryl Horloge Simple

Widget Android 1×1 pour Samsung Galaxy.

- Heures au-dessus d’un trait, minutes en dessous.
- Appui : ouvre Horloge Samsung.
- Petit `+` lorsqu’un réveil est programmé.
- Avec accès aux notifications, tente d’afficher le minuteur/chronomètre Samsung actif depuis sa notification persistante.

## Important

L’intégration minuteur/chronomètre dépend de la structure de notification de la version Samsung Clock installée. La détection du réveil et l’ouverture d’Horloge Samsung utilisent des API Android publiques.
